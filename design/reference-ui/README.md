# Neokey UI reference concepts

Thư mục này lưu các mockup giao diện để tham khảo cho những lần thiết kế sau.
Chúng **không phải giao diện hiện đang được phát hành** và không được dùng làm
ảnh chụp sản phẩm trong README chính.

- `neokey-config-concept.svg`: nguồn vector của concept cửa sổ cấu hình.
- `neokey-config-concept.png`: bản xem trước PNG 2×.
- `neokey-shorthand-concept.svg`: nguồn vector của concept bảng gõ tắt.
- `neokey-shorthand-concept.png`: bản xem trước PNG 2×.

Ảnh giao diện thật dùng trong README nằm tại `assets/neokey-config.png` và
`assets/neokey-shorthand.png`.
